# Licensing status

This file is a status notice. The operative license for this repository is the Apache License, Version 2.0, in [LICENSE](LICENSE).

## Current license

Apache-2.0 is the only license currently in effect for this public repository. No SSPL license or Pro license is currently in effect.

## Planned commercial edition

The intended product model is an Apache-2.0 community edition plus a paid Pro edition under separate commercial terms. Pro is not currently available, and its license terms have not been issued. SSPL is a possible future option for Pro only; it has not been adopted.

Any future change will identify the affected edition and releases and provide applicable license terms explicitly. Contributor rights and the policy for accepting third-party contributions before offering alternate terms remain undecided.
